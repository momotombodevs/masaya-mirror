Funciones

  • Una ventana por dispositivo. Con barra de navegación bajo la pantalla.
  • Control completo. Toques, multitouch, arrastre, rueda y teclado con acentos.
  • Captura y grabación. Desde la barra o con atajos. Graba a 16 Mbps.

  • Claro y oscuro. Sigue el tema del sistema. Español e inglés.
  • Privado. Sin cuenta, sin nube, sin telemetría.

Instalar

Descarga el instalador de tu sistema desde la última versión: .dmg para macOS, .exe para Windows y .AppImage para Linux.

Los instaladores aún no están firmados. En macOS usa clic derecho → Abrir; en Windows, Más información → Ejecutar de todas formas.

Desde el código

Requiere Node.js 20 o superior y pnpm 10.

pnpm install
pnpm dev

Primeros pasos

  1. En el teléfono, activa las Opciones de desarrollador y la Depuración USB.
  2. Ten adb (Android platform-tools) instalado. Si la app no lo encuentra, te guía para descargarlo o elegirlo.
  3. Conecta el teléfono y acepta el aviso de depuración. Pasará de Sin autorizar a Listo.
  4. Haz doble clic en el dispositivo para abrir el espejo.

Conectar por Wi-Fi

Pulsa ⌘⇧W (macOS) o Ctrl Shift W y escanea el QR desde el teléfono: Opciones de desarrollador → Depuración inalámbrica → Vincular con código QR. Ambos deben estar en la misma red.

Problemas frecuentes

«ADB no encontrado»

Instala platform-tools o define ADB_PATH con la ruta del ejecutable.

El dispositivo aparece «Sin autorizar»

Acepta el diálogo de depuración USB en el teléfono.

El QR no encuentra el teléfono

Deben estar en la misma red y esta debe permitir mDNS. Prueba con otra red o por USB.

La imagen va con retraso

Baja la calidad a «Equilibrada» en Ajustes.
